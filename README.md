# Snake Game

## 🐍 Jogo da Cobrinha com Canvas em JavaScript

O **Snake Game** é uma implementação simples e funcional do clássico jogo da cobrinha, desenvolvido utilizando **HTML**, **CSS** e **JavaScript** com foco na API **Canvas** para a renderização do jogo. Este projeto demonstra habilidades em lógica de jogos, manipulação de eventos de teclado e uso de elementos gráficos do HTML5.

### ✨ Funcionalidades em Destaque

*   **Renderização com Canvas:** O jogo utiliza o elemento `<canvas>` do HTML5 para desenhar o cenário, a cobra e a comida, proporcionando um controle preciso sobre os gráficos.
*   **Lógica de Jogo Completa:** Implementação da mecânica de movimento, crescimento da cobra, detecção de colisão com as bordas e com o próprio corpo.
*   **Controle por Teclado:** A cobra é controlada pelas setas do teclado.
*   **Pontuação:** O jogo registra a pontuação do jogador.

### 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso Principal |
| :--- | :--- |
| **HTML5** | Estrutura e inclusão do elemento `<canvas>`. |
| **CSS3** | Estilização da página e do contêiner do jogo. |
| **JavaScript** | Lógica do jogo, manipulação do Canvas, controle de eventos e estado. |
| **Canvas API** | Renderização gráfica do jogo. |

### 🚀 Como Jogar

Para jogar, basta clonar o repositório e abrir o arquivo `index.html` em seu navegador web:

```bash
# 1. Clone o repositório
git clone https://github.com/BrizidoAndre/Snake-Game.git

# 2. Navegue até o diretório do projeto
cd Snake-Game

# 3. Abra o arquivo index.html no seu navegador
# (Exemplo para Linux/macOS)
open index.html
# (Exemplo para Windows)
start index.html
```
